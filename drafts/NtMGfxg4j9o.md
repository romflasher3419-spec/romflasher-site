This is the update I would send a friend rather than film properly. Coding,
Python and the custom ROM work are all still going. Nothing has been abandoned,

If you have been waiting to hear what is happening, that is the honest version.
Things are spread across a few projects at once, so I am not going to throw out

## What is actually running

- **The Python side.** Ongoing. This is the part that does the quiet work

- **The tool website.** Still in progress. Layout, tool writes and the download

## What is not in this clip

No flashing. No file walkthrough. No install steps, no downloads opened, no

## Why no dates

Because I have watched what happens when people promise a date and miss it. You
get a comment asking where the file is, then another one, then people assume the
project died. Better to say it is moving and show you when it lands.

The website work and the ROM work run side by side. Coding keeps the rest glued
together. When there is something you can download and use, it will get a proper
video with the steps on screen, not a status note.

## What you can do while you wait

If you are keen to flash something now, you do not need to wait for any of this.
The free Rom Flasher tool and the ADB and fastboot files are already available in
the downloads listed with this video, and they are the same ones I use.

A few things worth doing before your next flash, whatever build you pick:

- **Back up.** Unlocking the bootloader wipes the phone, and so does a clean
  flash. Get your photos and files off the device first.
- **Check the model.** A build for a different variant will flash happily and
  then refuse to boot. Match it exactly.
- **Read the install notes twice.** Small details like a required format step or
  a specific recovery version are where most dead phones come from.
- **Keep your files handy.** Once you have the platform tools and the driver, you
  are set for every flash after this one.
